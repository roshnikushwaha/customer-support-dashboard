# Customer Support Dashboard

A responsive customer support dashboard built with React.js, Tailwind CSS, Zustand, and a mock REST API.

## Features

- Dashboard statistics
- Total, Open, In Progress and Resolved ticket counts
- Search tickets by customer name, email, subject or ticket ID
- Filter tickets by status
- Filter tickets by priority
- View complete ticket details
- Update ticket status
- Customer contact information
- Previous conversation/messages
- Loading state
- Error state with retry
- Empty search/filter state
- Responsive desktop and mobile UI

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Zustand
- Lucide React
- JSON Server
- REST API
